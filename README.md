# ViaVisuals
Older clients normally see placeholders for blocks, items and mobs. That’s a pain almost every ViaVersion/ViaBackwards user recognizes!

ViaVisuals is a project that tries to make Minecraft on older clients (1.16+) see the world almost the same as the servers native version! 
It hooks into ViaVersion and ViaBackwards by removing its placeholders with actual animated models, textures and functionality just like vanilla Minecraft.
